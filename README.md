# httpflare

Утилита для **нагрузочного тестирования** HTTP: задаёте URL, конкурентность и
длительность — получаете отчёт по запросам, задержкам и ошибкам.

## Возможности

- Конкурентные воркеры с настраиваемым лимитом частоты
- Отчёт: RPS, p50/p95/p99, ошибки, коды ответов
- Плавная остановка по сигналу

## Сборка

```bash
go build -o httpflare .
```

## Использование

```bash
./httpflare -url https://example.com -c 200 -d 30s -rate 100
```

| Флаг | Описание |
|------|----------|
| `-url` | целевой адрес |
| `-c` | число воркеров |
| `-d` | длительность |
| `-rate` | максимум запросов в секунду (0 — без лимита) |
